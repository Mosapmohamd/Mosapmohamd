### 🚀 Featured Projects

#### 🔹 [Eliara — AI Analytics Platform](https://github.com/CarFLex-Team/Eliara-V2)
Enterprise, read-only AI analytics platform built for a real production database (378 tables, 464 views, 3.9GB SQLite refreshed from SAP Business One). Two-model LLM architecture — Claude Sonnet as orchestrator, Claude Haiku for governed SQL generation — with hybrid semantic + BM25 retrieval, streaming responses, multi-company isolation, and an anomaly-detection layer for business owners.
`FastAPI` `Claude API` `Ollama` `SQLite` `Docker` `sentence-transformers`

#### 🔹 [Pathora — AI Career Assessment Platform](https://github.com/Mosapmohamd/Pathora)
Graduation project (team of 5, led by me). Full-stack platform that takes a CV/JD, predicts job titles with an LLM, generates personalized exams, and recommends courses — with a dual-provider LLM layer (Ollama locally / Hugging Face API) switchable via config.
`FastAPI` `SQLAlchemy` `React 19` `Vite` `JWT` `Qwen2.5`

#### 🔹 [Sola POS — Desktop Point of Sale System](https://github.com/Mosapmohamd/Sola)
Production-ready desktop POS for restaurants and cafés, built as a commercial product. Full order lifecycle, cash-shift management, role-based access, reporting dashboards, and a self-contained embedded deployment (no Docker required on the client machine).
`Electron` `React` `TypeScript` `FastAPI` `PostgreSQL` `Clean Architecture`

#### 🔹 [Tourism Sentiment Analysis & Recommendation System](https://github.com/Mosapmohamd/Sentiment-Analysis-for-TripAdvisor-and-Quora-Egypt)
Analyzed 30,000+ Tripadvisor/Quora reviews on Egypt's tourism sites, comparing 8 ML/DL models and selecting a BiLSTM (90.09% accuracy, 89.9% F1) for its strength on imbalanced, minority-class (negative) reviews. Paired with an LLM recommendation engine (Google Gemini via LangChain) that turns negative feedback into actionable suggestions, deployed as a live Streamlit app.
`Python` `TensorFlow/Keras` `BiLSTM` `LangChain` `Gemini` `Streamlit`
